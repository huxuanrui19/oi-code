# T634638 序列划分

## 题目描述

给定一个长度为 $n$ 的数字串 $S$，将其划分成若干段连续的子串，显然一共有 $2^{n-1}$ 种划分方法。给定一个整数 $D$，你希望划分方案中，如果我们把每个子串当作一个十进制下的数字(可以有前导 $0$ )，那么不存在两个相邻的子串不被 $D$ 整除。

输出方案总数对 $10^9+7$ 取模的结果。

## 输入格式

一行，一个数字串 $S$ 和数字 $D$。

## 输出格式

输出一个数，表示答案。

## 输入输出样例 #1

### 输入 #1

```
0145217 7
```

### 输出 #1

```
16
```

## 输入输出样例 #2

### 输入 #2

```
100100 10
```

### 输出 #2

```
30
```

## 输入输出样例 #3

### 输入 #3

```
下载附件可见
```

### 输出 #3

```
下载附件可见
```

## 说明/提示

**数据规模与说明**

测试数据共十组

测试点 1 满足 $|S|\leq 20$.

测试点 2,3 满足 $|S|\leq 1000$.

测试点 4,5,6 满足 $\gcd(D,10)=1$.

对于 $100\%$ 的数据，满足$|S|\leq 5 × 10^5,1\leq D\leq10^6$。
