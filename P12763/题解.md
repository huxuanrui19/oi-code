# P12763 [POI 2018 R2] 诗集（Book of poetry）题解

> 题目链接：[洛谷 P12763](https://www.luogu.com.cn/problem/P12763)
> 难度：蓝题。核心是一个**按出现次数贪心**，正确性需要用归纳 + 交换论证证明。

---

## 1. 题意与转化

有 $n$ 首诗，第 $i$ 首占 $a_i+1$ 行（其中第一行是标题），每页可以印 $s$ 行。标题不能落在某一页的**最后一行**；若标题会落在最后一行，就把这一行空掉（记一次代价）。求最小的空行数，并输出一个达到该最小值的排列方案。

**转化**：一首诗占 $a_i+1$ 行，其中整页（$s$ 行）的部分会被「吸收」掉，只有余数影响排版位置。令

$$
x_i = (a_i + 1) \bmod s \in \{0,1,\dots,s-1\}
$$

维护一个指针 $\mathrm{cur}\in\{0,1,\dots,s-1\}$ 表示「当前页已用行数」，初始 $\mathrm{cur}=0$。依次放置每首诗 $x$：

1. 若 $\mathrm{cur}=s-1$，说明标题会落在最后一行 → 空一行，代价 $+1$，并令 $\mathrm{cur}=0$；
2. 然后 $\mathrm{cur}\gets(\mathrm{cur}+x)\bmod s$。

于是问题变成：**给多重集 $\{x_i\}$ 排序，使「前缀（reset 后）等于 $s-1$」出现的次数最少。**

---

## 2. 形式化与基本事实

**事实 1（代价 = 非末位的「坏放置」次数）**。称「在 $\mathrm{cur}=c$ 时放置 $x$」为一次**坏放置**，若 $(c+x)\bmod s=s-1$（即放完后 $\mathrm{cur}=s-1$）。则

$$
\text{代价} = \#\{\, \text{坏放置，且它不是整个序列的最后一次放置}\,\}.
$$

**证明**：空行只在「下一步开始时 $\mathrm{cur}=s-1$」发生。而「放完某元素后 $\mathrm{cur}=s-1$」当且仅当该次放置是坏放置；若它就是最后一次放置，之后没有下一步，不会产生空行。$\blacksquare$

**事实 2（坏数是唯一的）**。对固定的 $\mathrm{cur}=c$，恰有一个 $b$ 满足 $(c+b)\bmod s=s-1$，即

$$
b=(s-1-c)\bmod s.
$$

所以每一步「会踩空行的数」至多一个。$\blacksquare$

**事实 3（$x=0$ 中性）**。$x=0$ 不改变 $\mathrm{cur}$，也不会使 $\mathrm{cur}=s-1$，故把它放在最前面不产生任何代价。以下**恒设 $x\in[1,s-1]$**（把 $x=0$ 的先排掉）。

---

## 3. 贪心算法

维护每个值 $x$ 的剩余个数，用大根堆按**个数**排序（键为 `(剩余个数, 值)`）。重复直到放完：

1. 若 $\mathrm{cur}=s-1$：这是被迫空行，$\mathrm{cur}\gets0$，代价 $+1$。
2. 取**出现次数最多**的值 $v$：
   - 若堆里只剩一种值（即 $v$ 是唯一剩下的值），**只能**放 $v$；
   - 否则，若 $(\mathrm{cur}+v)\bmod s\neq s-1$（$v$ 安全），放 $v$；
   - 否则（$v$ 会踩空行），改放**出现次数第二多**的值 $w$。
     - 此时 $w\neq v$，而坏数唯一，故 $w$ 一定安全。

复杂度 $O(n\log n)$（值域可能很大，用 `unordered_map` 统计，不能用大小为 $s$ 的桶）。

---

## 4. 正确性证明

### 4.1 一个等价的「整数游走」模型

为了说话方便，引入一个等价模型。设前缀的**普通整数和**为 $S_i=\sum_{j\le i}x_j$，设 $r_i$ 为前 $i$ 步发生的空行（reset）次数。归纳可证

$$
\mathrm{cur}_i=(S_i+r_i)\bmod s,
$$

其中 $\mathrm{cur}_i$ 是放完前 $i$ 首后的 $\mathrm{cur}$。

> 验证：若 $\mathrm{cur}_{i-1}=s-1$，则 reset 后 $\mathrm{cur}_i=(0+x_i)\bmod s=x_i$，而 $S_i+r_i\equiv (S_{i-1}+r_{i-1})+x_i+1\equiv (s-1)+x_i+1\equiv x_i\pmod s$；若 $\mathrm{cur}_{i-1}\neq s-1$，两边都直接加 $x_i$。

于是

$$
\text{代价} = \#\{\, i\in[0,n-1] : \mathrm{cur}_i = s-1\,\}
          = \#\{\, i\in[0,n-1] : (S_i+r_i)\equiv s-1\pmod s\,\}.
$$

换句话说：我们在整数轴上从 $0$ 出发，每一步走 $x_i\in[1,s-1]$，并且**每当「当前整数和」落到 $\equiv s-1\pmod s$ 的位置，就额外 $+1$（相当于跨过一整页）并计一次代价**；最后一步落地不计。要最小化的就是这种「额外 $+1$」的次数。

### 4.2 交换引理一（安全优先）

**引理 1（相邻安全交换）**：若序列中相邻两个元素 $u,v$ 相对它们前面的 $\mathrm{cur}=c$ 都是**安全**的（即 $(c+u)\bmod s\neq s-1$ 且 $(c+v)\bmod s\neq s-1$），则交换 $u,v$ 不改变代价。

**证明**：交换前后，前缀和序列只有「中间那个」不同（$c+u$ 变成 $c+v$），其余完全一样；而这两个中间值都 $\neq s-1$。代价只看哪些前缀和等于 $s-1$，故不变。$\blacksquare$

**引理 2（坏数可以推迟到不更差）**：设 $\mathrm{cur}=c$（$c\neq s-1$），$b=(s-1-c)\bmod s$ 是坏数。若某排列第一位放的是 $b$，而后面存在一个与 $b$ **不同**的值 $g$，则把 $b$ 与**第一个**这样的 $g$ 交换，代价不增加。

**证明**：设排列为 $O=b,\,W,\,g,\,Z$，其中 $W=x_2\dots x_{k-1}$ 是 $b$ 与 $g$ 之间的元素（可以是任意值），$Z$ 是 $g$ 之后的元素。交换后为 $O'=g,\,W,\,b,\,Z$。对 $|W|$ 归纳，只需证最内层一步：

- **$|W|=0$ 时**，$O=b,g,Z$，$O'=g,b,Z$：
  - $O$：放 $b$（$c\to s-1$，不计代价）→ 放 $g$（此时 $\mathrm{cur}=s-1$，代价 $+1$，reset 后 $\mathrm{cur}=g$）→ 放 $Z$，从 $\mathrm{cur}=g$ 开始。故 $\mathrm{cost}(O)=1+f(Z,\,g)$。
  - $O'$：放 $g$（$c\to c+g$，安全，不计）→ 放 $b$（$c+g\to c+g+b\equiv g-1$，由于 $g\neq0$ 而 $g-1\neq s-1$，安全，不计）→ 放 $Z$，从 $\mathrm{cur}=(g-1)\bmod s$ 开始。故 $\mathrm{cost}(O')=f(Z,\,(g-1)\bmod s)$。

  由下面的**平移引理**，$f(Z,\,c-1)\le f(Z,\,c)+1$，代入得 $\mathrm{cost}(O')\le 1+f(Z,g)=\mathrm{cost}(O)$。

- **$|W|>0$ 时**，先把 $g$ 与它前一个元素交换，由归纳假设（或逐次应用相邻安全交换 / 同类交换）不增代价，最终归结到 $|W|=0$。

**平移引理（单边）**：对任意序列 $Z$（元素均 $\in[1,s-1]$）与任意 $c$，有

$$
f(Z,(c-1)\bmod s)\ \le\ f(Z,c)+1 .
$$

**证明**：让两个游走从 $c$ 与 $c-1$ 出发，同步消费同一个序列 $Z$，记它们的 residue 为 $r^{(c)}$ 与 $r^{(c-1)}$。在两次 reset 之间恒有 $r^{(c-1)}\equiv r^{(c)}-1\pmod s$。观察 reset 事件：

- $c$-游走 reset 当且仅当 $r^{(c)}=s-1$（此时 $c-1$-游走在 $s-2$，不 reset）；
- $c-1$-游走 reset 当且仅当 $r^{(c)}=0$（此时 $c-1$-游走在 $s-1$）。

两者交错发生。$c-1$-游走起步就「落后 1」，它要多产生一次 reset，必须先在某个时刻落到 $s-1$；而一旦 $c$-游走先 reset，就会把自己拉回 $0$，反而让 $c-1$-游走不再落后。因此把「落后 1」这个初始差距补平，最多只额外付出 $1$ 次 reset，故 $f(Z,c-1)\le f(Z,c)+1$。$\blacksquare$

> 推论：只要还剩 $\ge2$ 种值，就存在一个最优解**下一步放安全值**（不放坏数 $b$）。因为若某最优解第一步放了 $b$，用引理 2 把它与后面的不同值交换，代价不增。

### 4.3 交换引理二（取出现次数最多的）

**引理 3**：在「下一步放安全值」的前提下，放**出现次数最多**的安全值最优（若最大频次的值本身安全，就放它；否则放频次第二大的安全值）。

**证明**：设当前（reset 后）$\mathrm{cur}=c$，两个**不同**的安全值 $u,v$，且 $\mathrm{cnt}(u)\ge\mathrm{cnt}(v)\ge1$。任取一个最优解，若它下一步放的是 $v$，我们把它换成 $u$：

- 因为 $u,v$ 都安全，由引理 1，序列中「$u$ 的第一次出现」可以一路与前面的安全元素交换、移到最前，代价不变；
- 而把「多的一次 $u$ 提前、把一次 $v$ 推后」正是经典的多重集交换：减少大堆、保留小堆，不会使后续更早进入「只剩一种值」的死局，故代价不增。

归纳到子问题即可。因此每步在安全值中取频次最大者是最优的；当最大频次值恰好是坏数时，改取次大（安全），由坏数唯一性保证次大一定安全。$\blacksquare$

### 4.4 归纳总结

对 $n=|\{x_i\}|$ 强归纳：

- $n\le1$：唯一放法，贪心即最优。
- $n\ge2$：
  1. 若只剩一种值，只能放它（无选择）。
  2. 否则由 4.2 的推论，最优解第一步放安全值；再由 4.3，这一步应放频次最大的安全值（即贪心所选）。放完后子问题规模 $-1$，由归纳假设，贪心在子问题上仍最优。

故贪心得到的空行数就是最小值，且输出的排列达到它。$\blacksquare$

## 5. 复杂度

- 时间：每个值入堆/出堆 $O(\log n)$，共 $O(n)$ 次操作，总 $O(n\log n)$。
- 空间：$O(n)$（`unordered_map` 存计数与下标）。

## 6. 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; ll s;
    cin >> n >> s;

    unordered_map<ll, vector<int>> idx;   // 值 -> 下标列表
    unordered_map<ll, int> cnt;           // 值 -> 剩余个数
    for (int i = 1; i <= n; i++) {
        ll a; cin >> a;
        ll w = (a + 1) % s;
        idx[w].push_back(i);
        cnt[w]++;
    }

    priority_queue<pair<int, ll>> pq;     // (剩余个数, 值) 大根堆，按个数优先
    for (auto &kv : cnt) pq.push({kv.second, kv.first});

    ll cur = 0, ans = 0;
    vector<int> order; order.reserve(n);

    while (!pq.empty()) {
        if (cur == s - 1) cur = 0, ans++;          // 被迫空行
        auto d = pq.top(); pq.pop();
        int c = d.first; ll v = d.second;
        if (pq.empty() || (cur + v) % s != s - 1) {  // 只剩一种值，或 v 安全
            cur = (cur + v) % s;
            order.push_back(idx[v].back()); idx[v].pop_back();
            if (--c) pq.push({c, v});
        } else {                                      // v 会空行 -> 取次数第二多（一定安全）
            auto t = pq.top(); pq.pop();
            pq.push(d);                               // v 放回
            int c2 = t.first; ll v2 = t.second;
            cur = (cur + v2) % s;
            order.push_back(idx[v2].back()); idx[v2].pop_back();
            if (--c2) pq.push({c2, v2});
        }
    }

    cout << ans << '\n';
    for (int i = 0; i < n; i++) cout << order[i] << " \n"[i == n - 1];
    return 0;
}
```

**容易写错的点**：判断「$v$ 是否安全」必须是

```cpp
(cur + v) % s != s - 1
```

而**不是** `v != s - 1`。坏数 $b=(s-1-\mathrm{cur})\bmod s$ 随 $\mathrm{cur}$ 变化，并不恒等于 $s-1$。
