# P12763 [POI 2018 R2] 诗集（Book of poetry）题解

> 题目链接：[洛谷 P12763](https://www.luogu.com.cn/problem/P12763)
> 难度：蓝题。核心是一个**按出现次数贪心**，第 4 节分别证明为什么可以避开坏数，以及为什么在安全值中取剩余次数最多的一个。

---

## 1. 题意与转化

有 $n$ 首诗，第 $i$ 首占 $a_i+1$ 行（其中第一行是标题），每页可以印 $s$ 行。标题不能落在某一页的**最后一行**；若标题会落在最后一行，就把这一行空掉（记一次代价）。求最小的空行数，并输出一个达到该最小值的排列方案。

**转化**：一首诗占 $a_i+1$ 行，其中整页（$s$ 行）的部分会被「吸收」掉，只有余数影响排版位置。令

$$
x_i = (a_i + 1) \bmod s \in \{0,1,\dots,s-1\}
$$

维护一个指针 $\mathrm{cur}\in\{0,1,\dots,s-1\}$ 表示「当前页已用行数」，初始 $\mathrm{cur}=0$。依次放置每首诗 $x$：

1. 若 $\mathrm{cur}=s-1$，说明标题会落在最后一行 → 空一行，代价 $+1$，并令 $\mathrm{cur}=0$；
2. 然后 $\mathrm{cur}\gets(\mathrm{cur}+x)\bmod s$。

于是问题变成：**给多重集 $\{x_i\}$ 排序，使「前缀（reset 后）等于 $s-1$」出现的次数最少。**

---

## 2. 形式化与基本事实

**事实 1（代价 = 非末位的「坏放置」次数）**。称「在 $\mathrm{cur}=c$ 时放置 $x$」为一次**坏放置**，若 $(c+x)\bmod s=s-1$（即放完后 $\mathrm{cur}=s-1$）。则

$$
\text{代价} = \#\{\, \text{坏放置，且它不是整个序列的最后一次放置}\,\}.
$$

**证明**：空行只在「下一步开始时 $\mathrm{cur}=s-1$」发生。而「放完某元素后 $\mathrm{cur}=s-1$」当且仅当该次放置是坏放置；若它就是最后一次放置，之后没有下一步，不会产生空行。$\blacksquare$

**事实 2（坏数是唯一的）**。对固定的 $\mathrm{cur}=c$，恰有一个 $b$ 满足 $(c+b)\bmod s=s-1$，即

$$
b=(s-1-c)\bmod s.
$$

所以每一步「会踩空行的数」至多一个。$\blacksquare$

**事实 3（余数为零的诗）**。把所有 $0$ 移到开头不会增加代价。夹在两首非零诗之间的一串 $0$ 不改变页内位置。若前一首恰好结束在 $s-1$，移走这些 $0$ 后，同一个空行会在下一首非零诗前补上。若这些 $0$ 原本在书末，移走它们还可能省去最后一个空行。

参考代码把 $0$ 也放在堆里。每次选诗之前已经处理了空行，此时 $0$ 总是安全。跳过代码选出的 $0$ 来看，每次选出的非零值仍然是剩余非零值中频次最高的安全值（如果全都不安全，就只剩一种非零值）。只要堆里还有 $0$，代码就不会选坏数，所以也不会出现「最后一首非零诗落在 $s-1$，还要为末尾的 $0$ 补空行」的情况。因此只需证明非零序列的贪心。若全为 $0$，答案就是 $0$。

---

## 3. 贪心算法

维护每个值 $x$ 的剩余个数，用大根堆按**个数**排序（键为 `(剩余个数, 值)`）。重复直到放完：

1. 若 $\mathrm{cur}=s-1$：这是被迫空行，$\mathrm{cur}\gets0$，代价 $+1$。
2. 取**出现次数最多**的值 $v$：
   - 若堆里只剩一种值（即 $v$ 是唯一剩下的值），**只能**放 $v$；
   - 否则，若 $(\mathrm{cur}+v)\bmod s\neq s-1$（$v$ 安全），放 $v$；
   - 否则（$v$ 会踩空行），改放**出现次数第二多**的值 $w$。
     - 此时 $w\neq v$，而坏数唯一，故 $w$ 一定安全。

频次相同时可以任选一个安全值。代码用 `unordered_map` 统计出现过的余数，堆只存非空的类别。

## 4. 正确性证明

### 4.1 一个等价的「整数游走」模型

为了说话方便，引入一个等价模型。设前缀的**普通整数和**为 $S_i=\sum_{j\le i}x_j$，设 $r_i$ 为前 $i$ 步发生的空行（reset）次数。归纳可证

$$
\mathrm{cur}_i=(S_i+r_i)\bmod s,
$$

其中 $\mathrm{cur}_i$ 是放完前 $i$ 首后的 $\mathrm{cur}$。

> 验证：若 $\mathrm{cur}_{i-1}=s-1$，则 reset 后 $\mathrm{cur}_i=(0+x_i)\bmod s=x_i$，而 $S_i+r_i\equiv (S_{i-1}+r_{i-1})+x_i+1\equiv (s-1)+x_i+1\equiv x_i\pmod s$；若 $\mathrm{cur}_{i-1}\neq s-1$，两边都直接加 $x_i$。

于是

$$
\text{代价} = \#\{\, i\in[0,n-1] : \mathrm{cur}_i = s-1\,\}
          = \#\{\, i\in[0,n-1] : (S_i+r_i)\equiv s-1\pmod s\,\}.
$$

换句话说：我们在整数轴上从 $0$ 出发，每一步走 $x_i\in[1,s-1]$，并且**每当「当前整数和」落到 $\equiv s-1\pmod s$ 的位置，就额外 $+1$（相当于跨过一整页）并计一次代价**；最后一步落地不计。要最小化的就是这种「额外 $+1$」的次数。

### 4.2 有安全值时，为什么可以推迟坏数？

设当前位置为 $c$，已经处理了本步开始前的空行。若某个最优排列以坏数 $b$ 开头，取它后面第一个不同的值 $g$。原排列的开头一定是 $b^m g$，其中 $m\ge1$，$b^m$ 表示连续 $m$ 个 $b$。比较 $b^m g$ 和 $g b^m$。

- 原顺序放完第一个 $b$ 就到达 $s-1$。后面至少还有 $g$，所以必付一个空行，然后从 $0$ 开始印 $b^{m-1}g$。
- 新顺序先放 $g$，这一步安全，因为坏数只有 $b$。如果这段内没有付空行，新顺序就在这段里省了至少一行。如果段内付了第一个空行，那么此时至少已印了一个 $b$，从 $0$ 开始还要印的只是一段 $b^q$，其中 $q\le m-1$。这正是原顺序第一次付费后所印序列的一个前缀，段内后续付费次数也就不超过原顺序。

还要比较两段接上**相同后缀**之后的代价。令 $T$ 为从书首算起已经用掉的总行数（含空行）。印一首长度为 $L$ 的诗后，总行数变为

$$
F_L(T)=T+\mathbf 1_{T\bmod s=s-1}+L.
$$

这个函数在整数上单调不减。起点往后移一行，即使恰好省掉了原来的一个空行，终点也只会相同或更晚。两种顺序用的诗相同，新顺序段内的空行又更少或相等，故段末的 $T$ 更小或相等。对相同后缀依次应用 $F_L$，这一关系一直保持到书末。诗的总长度固定，最终总行数更小或相等，就说明空行数更少或相等。因此一定存在以安全值开头的最优排列。

### 4.3 为什么要在安全值中比较频次？

两个相邻的值如果在同一起点都安全，交换它们会得到相同的段末位置。这个结论只能用在满足条件的那一对上。例如 $s=4$，从 $0$ 出发，三个余数 $1,3,2$ 各出现一次。

| 顺序 | 依次放完各首后的页内位置 | 空行数 |
| --- | --- | --- |
| $1,3,2$ | $1,0,2$ | $0$ |
| $2,1,3$ | $2,3,3$（印最后一首前补空行） | $1$ |
| $2,3,1$ | $2,1,2$ | $0$ |

$2$ 在开头安全，但把它移到最前并保持其他诗的相对顺序，会多付一个空行。贪心选 $2$ 仍然可以最优，它接下来会选 $3$。

频次确实会影响答案。同样取 $s=4$，若剩下的是 $1,1,2$，则 $1$ 和 $2$ 起初都安全。先选 $2$ 就只剩 $1,1$，顺序 $2,1,1$ 必付一行。先选高频的 $1$，再印 $1,2$，三个落点为 $1,2,0$，全程零空行。

下面按最高频是否并列来证明堆的选择，分类思路参见 [SZwinsun 的题解](https://www.cnblogs.com/SZwinsun/p/19253461)。

#### 情形一：至少两个值并列最高频

**从任何已经处理好空行的位置出发，只要最高频并列，贪心就能以零个新增空行印完。** 设最高频为 $h$，并列者共有 $k\ge2$ 个。对 $h$ 归纳。

还有至少两个值的频次为 $h$ 时，至多一个是坏数，所以贪心总能选一个安全的最高频值。前 $k-1$ 次选的是不同的并列者，选过的频次降为 $h-1$。记最后一个仍有 $h$ 份的值为 $x$。

- 若 $h=1$，只剩最后一首，即使落到 $s-1$ 也不用付费。
- 若 $h>1$ 且 $x$ 安全，直接选 $x$。原先的 $k$ 个值又在 $h-1$ 处并列，应用归纳假设。
- 若 $h>1$ 且 $x$ 是坏数，贪心选一个频次为 $h-1$ 的 $y$。放 $y$ 是安全的，随后放 $x$ 也安全，因为原本放 $x$ 的落点是 $s-1$，现在落点变成 $s-1+y\not\equiv s-1\pmod s$。若选 $y$ 前至少有两个频次为 $h-1$ 的值，放完 $y,x$ 后，$x$ 和另一个值在 $h-1$ 处并列，再用归纳假设。

最后还剩一种情况：选 $y$ 前只有它的频次为 $h-1$。前面已经选过的 $k-1$ 个并列者都还有 $h-1$ 份，所以 $k=2$，上一步放的正是 $y$。从上一步之前的位置 $p$ 看，已经知道 $p+y+x\equiv s-1\pmod s$，而 $p\ne s-1$。这一小段贪心会走 $y,y,x,x$。逐个核对，四个落点相对坏位置 $s-1$ 的差分别为

$$
-x,\qquad y-x,\qquad y,\qquad x+y\pmod s.
$$

前三个非零，因为 $x,y$ 是不同的非零余数。最后一个也非零，否则 $p+y+x\equiv p$ 会推出 $p=s-1$。所以四步都安全。选完第二个 $y$ 后，其他值都至多剩 $h-2$ 份，接下来两次选 $x$ 确实符合堆的规则。此时 $x,y$ 都剩 $h-2$ 份，或已全部印完，或回到了更小的并列情形。归纳成立，也说明了频次并列时可以任意打破平局。

#### 情形二：起初有唯一最高频值 $d$

若后来第一次出现最高频并列，则在此之前 $d$ 一直是唯一最高频值（每步只减一份）。这段时间只要还有两种值就能选安全值，期间没有空行。并列后的部分由情形一保证也没有空行。因此只有在**贪心实际付了空行**时，才需要证明一个正的下界。这时从头到尾都没有出现过最高频并列：$d$ 安全就选 $d$，只有 $d$ 是坏数才选别的值，第一次付费时已经只剩 $d$。

若 $\gcd(d,s)>1$，从 $0$ 连续加 $d$ 只能到达这个公因数的倍数，永远到不了 $s-1$。贪心会一直安全地取 $d$，直到出现并列或全部印完。因此付费情形一定满足 $\gcd(d,s)=1$。

此时可以数清**其他每首诗最多能让我们多印几个 $d$**。令 $u$ 为 $d$ 模 $s$ 的逆元，$[z]_s$ 表示 $z$ 的最小非负余数。定义

$$
H(c)=[(s-1-c)u]_s,\qquad B=H(0)=[-u]_s>0.
$$

$H(c)$ 就是从位置 $c$ 连续印多少个 $d$ 会首次到达 $s-1$（若已在那里，取 $0$）。所以 $H=1$ 表示下一首若选 $d$ 就会落到坏位置。对**任意排列**检查 $H$ 的变化：

| 动作 | $H$ 的变化 | 原因 |
| --- | --- | --- |
| 印一个 $d$ | 恰好减 $1$ | 印诗前已处理空行，故 $H\ge1$ |
| 印一个 $y\ne d$ | 至多增加 $t_y=[-yu]_s$ | 新值为 $[H+t_y]_s$，取模只可能减去 $s$ |
| 补一个空行 | 恰好增加 $B$ | 位置从 $s-1$ 回到 $0$，即 $H$ 从 $0$ 回到 $B$ |

设共有 $D$ 个 $d$，把所有其他诗的 $t_y$ 按出现次数求和，记为 $A$。任意用了 $k$ 个空行的排列，初值为 $B$，终值非负，故

$$
0\le H_{\rm end}\le B-D+A+kB.
$$

贪心每次选 $y\ne d$ 时恰有 $H=1$。因为 $y\ne d$，所以 $t_y\ne s-1$（否则 $yu\equiv1$ 就会推出 $y=d$）。于是 $1+t_y\le s-1$，没有发生取模回绕，每个 $y$ 都**完整增加了 $t_y$**。若贪心用了 $K>0$ 个空行，上式右侧对贪心取等。最后一次补空行后 $H=B$，之后至少还有一个 $d$ 要印，且余下全是 $d$，所以 $H_{\rm end}<B$。因此

$$
B-D+A+(K-1)B=H_{\rm end}-B<0.
$$

这与任何合法排列的终值非负矛盾，故用 $K-1$ 个或更少空行都不可能。贪心用了 $K$ 个，恰好最优。这里也用到了题目的末位规则：最后一首落到 $s-1$ 时终值可以为 $0$，无需再补一行。

**例子。** 取 $s=5$，余数有六个 $2$ 和一个 $3$。此时 $d=2$，$u=3$，$B=2$，而 $t_3=[-9]_5=1$。若只用一个空行，最多支持 $2+1+2=5$ 个 $2$，所以至少需要两个空行。贪心的顺序是 $2,3,2,2\mid 2,2\mid 2$，两条竖线就是实际补空行的位置，正好达到下界。

## 5. 复杂度

- 时间：设不同余数有 $m$ 种，每首诗触发常数次堆操作，计入哈希表的均摊开销，总时间期望为 $O(n\log(m+1))$。
- 空间：$O(n)$（`unordered_map` 存计数与下标）。

## 6. 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; ll s;
    cin >> n >> s;

    unordered_map<ll, vector<int>> idx;   // 值 -> 下标列表
    unordered_map<ll, int> cnt;           // 值 -> 剩余个数
    for (int i = 1; i <= n; i++) {
        ll a; cin >> a;
        ll w = (a + 1) % s;
        idx[w].push_back(i);
        cnt[w]++;
    }

    priority_queue<pair<int, ll>> pq;     // (剩余个数, 值) 大根堆，按个数优先
    for (auto &kv : cnt) pq.push({kv.second, kv.first});

    ll cur = 0, ans = 0;
    vector<int> order; order.reserve(n);

    while (!pq.empty()) {
        if (cur == s - 1) cur = 0, ans++;          // 被迫空行
        auto d = pq.top(); pq.pop();
        int c = d.first; ll v = d.second;
        if (pq.empty() || (cur + v) % s != s - 1) {  // 只剩一种值，或 v 安全
            cur = (cur + v) % s;
            order.push_back(idx[v].back()); idx[v].pop_back();
            if (--c) pq.push({c, v});
        } else {                                      // v 会空行 -> 取次数第二多（一定安全）
            auto t = pq.top(); pq.pop();
            pq.push(d);                               // v 放回
            int c2 = t.first; ll v2 = t.second;
            cur = (cur + v2) % s;
            order.push_back(idx[v2].back()); idx[v2].pop_back();
            if (--c2) pq.push({c2, v2});
        }
    }

    cout << ans << '\n';
    for (int i = 0; i < n; i++) cout << order[i] << " \n"[i == n - 1];
    return 0;
}
```

**容易写错的点**：判断「$v$ 是否安全」必须是

```cpp
(cur + v) % s != s - 1
```

而**不是** `v != s - 1`。坏数 $b=(s-1-\mathrm{cur})\bmod s$ 随 $\mathrm{cur}$ 变化，并不恒等于 $s-1$。
