## T1 median（中位数分割）

### 题面

对于一个长度为 `2k+1` 的数组，将其元素按非递减顺序排序后，第 `k+1` 位的数字称为该数组的**中位数**。例如 `[1]`、`[4,2,5]`、`[6,5,1,2,3]` 的中位数分别是 `1`、`4`、`3`。

给定一个长度为**偶数** `n` 的整数数组 `a`。判断是否可以将 `a` 分割成若干个长度为奇数的子数组，使得所有这些子数组的中位数都相等。

形式化地，你需要判断是否存在一个整数序列 `i_1, i_2, …, i_k`，满足：

- `1 = i_1 < i_2 < … < i_k = n+1`；
- `(i_2−i_1) mod 2 = (i_3−i_2) mod 2 = … = (i_k−i_{k−1}) mod 2 = 1`（每段长度都是奇数）；
- `f(a[i_1..(i_2−1)]) = f(a[i_2..(i_3−1)]) = … = f(a[i_{k−1}..(i_k−1)])`，其中 `a[l..r]` 表示子数组 `a_l, a_{l+1}, …, a_r`，`f(a)` 表示数组 `a` 的中位数。

**输入格式**：第一行一个偶数 `n`（`2 ≤ n ≤ 2·10^5`）——数组长度；第二行 `n` 个整数 `a_1, …, a_n`（`1 ≤ a_i ≤ 10^9`）。保证 `n` 是偶数。

**输出格式**：如果可以将 `a` 分割成若干个长度为奇数且中位数都相等的子数组，输出 `Yes`，否则输出 `No`。

**评分标准**：

| 分值 | 限制 |
|---|---|
| 3 | `n = 2` |
| 14 | 对所有 `i`，`1 ≤ a_i ≤ 2` |
| 12 | 对所有 `i < n`，`a_i ≤ a_{i+1}`（非递减） |
| 16 | 对所有 `i`，`1 ≤ a_i ≤ 3`，且每个值出现次数不超过 `n/2` |
| 17 | `n ≤ 100` |
| 18 | `n ≤ 2000` |
| 20 | 无额外限制 |

### 题解

**引理**：若三段长度均为奇数、中位数均为 `m` 的序列按任意顺序拼接，则拼接后的序列（长度仍为奇数）中位数仍为 `m`。

*证明*：设三段长度分别为 `2p+1, 2q+1, 2r+1`。中位数为 `m` 说明每段中 `< m` 的元素至多 `p, q, r` 个，总数至多为 `p+q+r`，恰为总长度一半。因此拼接后第 `(p+q+r+1)` 小的元素（即中位数）必为 `m`。∎

**结论**：设

- `pre[i]` = `a[1..i]` 的中位数（`i` 为奇数）；
- `suf[i]` = `a[i..n]` 的中位数（`n−i+1` 为奇数）。

则存在合法分割 **当且仅当** 存在奇数 `i` 满足 `pre[i] = suf[i+1]`。

*证明*：`n` 为偶数、每段长度为奇数 ⟹ 段数 `k` 为偶数且 `k ≥ 2`。取合法分割的第一刀 `i = i_2`（`i` 为奇数），第一段中位数为 `m`；由引理，后 `k−1` 段（奇数个奇数段）拼起来的中位数也是 `m`，即 `suf[i+1] = m = pre[i]`。反之，若 `pre[i] = suf[i+1] = m`，直接把 `a` 切成 `a[1..i]` 与 `a[i+1..n]` 两段（长度分别为奇数、奇数），由引理两段中位数均为 `m`。∎

**正解（20 分）**：用对顶堆 O(n log n) 递推所有奇数位置的 `pre` / `suf`：

- 大根堆 `p` 存较小的一半，小根堆 `q` 存较大的一半，维持 `|p| = |q| + 1`，`p.top()` 即当前中位数；
- `pre` 从前往后，每步把 `a_{i-1}, a_i` 两个元素插入并重平衡；`suf` 从后往前对称。

最后枚举奇数 `i` 判定 `pre[i] == suf[i+1]` 即可。复杂度 O(n log n)，空间 O(n)。

**部分分做法**：

- **3 分（n = 2）**：只能切成 `[a_1], [a_2]`，输出 `a_1 == a_2 ? Yes : No`。
- **17 分（n ≤ 100）**：枚举切点 `i`（奇数），对两段分别排序取中位数，O(n² log n)。
- **18 分（n ≤ 2000）**：同上，或预处理后每次 O(log n) 查询中位数（平衡树 / 两个 `multiset`），总 O(n² log n)。
- **14 分（a_i ∈ {1,2}）**：把 `1 → +1`、`2 → −1`，设前缀和 `P`。奇数段中位数为 `1` ⟺ 段和 `> 0`。于是 `pre[i] = suf[i+1]` ⟺ `P_i` 与 `P_n − P_i` 同号（奇数段和不为 0，符号确定），O(n) 判定。
- **16 分（a_i ∈ {1,2,3}）与 14 分通用技巧**：值域只有 `V` 种时，对每个候选中位数 `m`（即数组中出现过的值），用计数前缀和 `ge[v][i] = #{j ≤ i : a_j ≥ v}` 做到 O(1) 求任意奇数段的中位数（中位数 `= m` ⟺ `ge[m][段] ≥ (len+1)/2` 且 `ge[m+1][段] < (len+1)/2`）。对每个 `m` 扫一遍切点，总 O(nV)，V ≤ 3 时轻松通过。
- **12 分（非递减）**：非递减数组的奇前缀中位数为 `a_{(i+1)/2]`，奇后缀中位数直接定位，O(n) 判等；事实上用上面任意一种做法也都能过。

### 参考实现

见同目录 `median.cpp`（对顶堆写法，已与 std 对拍 500 组随机数据）。

## T2 tramcar（矿车与侧线）

### 题面

lbw 有 `N` 辆矿车，编号 `1` 到 `N`，在轨道上从左到右排成一列。最初第 `i` 辆矿车中有 `a_i` 颗宝石。

lbw 希望矿车排成一列，使得从左到右每辆矿车中的宝石数量非递减。为此，他计划**在所有矿车的右侧**修建一条从主轨道分岔出去的侧线。lbw 可以将侧线左侧的矿车移入侧线，允许其左侧的其他矿车在主轨道上从它旁边驶过。移入侧线的矿车可以一次一辆地移回主轨道：侧线上的矿车将移回至侧线的左侧，并且位于侧线左侧所有其他矿车的右侧（**后进先出**）。侧线可以使用任意多次。一旦矿车被移动到侧线的右侧，它就不能再向左移动。

（题面含 5 辆矿车的移动序列示意图：先移 4、5 入侧线，再让 2、3 通过，再把 4 移回主轨道……）

lbw 有 `K` 颗备用宝石，他可以将任意数量的备用宝石放入**空矿车**中。lbw 尚未修建侧线，他希望限制侧线容量以节省工作量。具有特定容量的侧线最多只能存放相应数量的矿车。假设 lbw 以最优方式将备用宝石放入矿车，那么需要修建的侧线**最小容量**是多少？

**输入格式**：第一行两个整数 `N, K`（`1 ≤ N ≤ 3·10^5`，`0 ≤ K ≤ 10^12`）；下一行 `N` 个整数 `a_1, …, a_N`（`0 ≤ a_i ≤ 10^6`），`a_i = 0` 表示第 `i` 辆是空矿车。

**输出格式**：输出一个整数——最优填数下的最小侧线容量。

**评分标准**：

| 分值 | N | K |
|---|---|---|
| 12 | ≤ 5000 | `K = 0` |
| 12 | ≤ 5000 | `K = 10^12` |
| 12 | ≤ 5000 | `0 ≤ K ≤ 10^12` |
| 20 | ≤ 3·10^5 | `K = 0` |
| 20 | ≤ 3·10^5 | `K = 10^12` |
| 24 | ≤ 3·10^5 | `0 ≤ K ≤ 10^12` |

### 题解

**先建立模型**。侧线接口在轨道右端，矿车整体向右移动，因此**最右侧的矿车**随时可以：

1. 直接通过接口向右驶出（下称"出站"）；
2. 被移入侧线（栈，容量 `M`）；
3. 侧线中的车可随时移回主轨道，且被放在当前剩余车的**最右侧**——于是它立刻成为下一辆可以行动的车。

先出站的车停在轨道右端，后出站的车堵在它左边，所以**最终序列 = 出站顺序的逆序**。要求最终序列非递减 ⟺ **出站序列的值非递增**。

**关键结论（K = 0）**：把矿车按值**从大到小**依次出站。当值为 `a_i` 的车 `i` 出站时，侧线里压着的恰好是"原始位置在 `i` 右侧、值比 `a_i` 小"的车（位置在 `i` 右侧且值更大的车已经出站；值相等的车不需要交换相对顺序）。因此

> **K = 0 时答案 = `max_i #{ j > i : a_j < a_i }`。**

右侧更小值的个数用树状数组从右往左扫即可，O(n log n)。

**一般情况（含空矿车）**：给容量 `M` 做可行性判定 `check(M)`：

- 对每辆非空车 `i`，设 `Q(i) = #{ j > i : a_j < a_i }`（**注意空车也算"潜在更小"**——若给它填的值比 `a_i` 小，它同样会压在 `i` 下方）。`i` 出站时栈深为 `Q(i)`，其中最多 `M` 辆可以真压栈，其余必须靠"填得 ≥ a_i 的右侧空车"消化，故要求
  `Q(i) ≤ M + #{ i 右侧的空车数 }`。
- 若某辆空车 `t` 被多辆车要求"填得 ≥ 各自的值"，只需取最大者。按空车从左到右编号 `t = 1 … cnt`，令
  `need[t] = max{ a_i 的排名 : R(i) > 0 且该要求落在 t 上 }`（`R(i) = max(Q(i) − M, 0)`），对 `need` 取前缀最大值后，最小总花费为 `Σ val[need[t]]`。
- `check(M) = (总花费 ≤ K)`，关于 `M` 单调，二分答案即可。单次判定 O(n log n)，总复杂度 **O(n log² n)**。

**实现细节**（易错点）：

- 树状数组求"右侧严格小于"的经典技巧：`add(rk_i + 1, 1)`、`query(rk_i)`——同值元素加在查询位置右侧，天然排除相等元素；
- **空车也要 add 进树状数组**（加在位置 1），否则右侧空车不计入 `Q(i)`，会得出错误答案（例如 `a = [3, 0, 2], K = 10^12`：正确答案是 1——把空车填成 3，序列变为 `[3,3,2]`，容量 1 足够；若忘记把空车计入 `Q`，会错输出 0）。

**部分分做法**：

- **12 + 20 分（K = 0）**：直接输出上面的公式。N ≤ 5000 时 O(n²) 枚举即可，N ≤ 3·10^5 需要树状数组/归并排序 O(n log n)。
- **12 + 20 分（K = 10^12）**：宝石无限。一种 N ≤ 5000 的稳过做法：枚举"所有空车填同一个值 v"，`v` 只需取 `n+1` 个候选（0 与每个 `a_i`），分别 O(n log n) 算答案取最小，总 O(n² log n)；N ≤ 3·10^5 时可以用与满分相同的判定（花费不受限时 `check` 退化为"是否存在合法填法"，更简单），或观察最优填法只与"每辆空车右侧的需求最大值"有关，按满分思路写。
- **12 分（N ≤ 5000，一般 K）**：二分 `M` + O(n²) 判定即可。

> ⚠️ 常见错误：用"排序后位置与原位置的错位最大值 `max|p_i − i|`"当答案。这是错的——反例 `a = [2, 3, 1]`：错位公式给 2，正确答案是 1（先把 1 压入侧线，2、3 依次出站，再放出 1）。

### 参考实现

见同目录 `tramcar.cpp`（满分做法：二分 + 树状数组判定，已与暴力 BFS 对拍通过，含上述反例）。

## T3 connected（复制图）

### 题面

lbw 有一个连通无向图 `G`，有 `N` 个编号 `1 … N` 的结点以及 `M` 条边（`2 ≤ N ≤ 10^5`，`N−1 ≤ M ≤ (N²+N)/2`）。`G` 可能包含自环，但不包含重边。

令 `f_G(a, b)` 为一个布尔函数：对 `1 ≤ a ≤ N` 与 `b ≥ 0`，如果存在一条从结点 `1` 到结点 `a` 的路径恰好经过了 `b` 条边，则函数值为真。一条边被经过多次会被计算相应次数。

小 P 想构造一个无向图 `G'`，使得对所有 `a, b` 都有 `f_{G'}(a, b) = f_G(a, b)`，并且 `G'` 的边数最少。求这个最小值。

每个输入包含 `T`（`1 ≤ T ≤ 5·10^4`）组独立测试用例，保证所有测试用例的 `N` 之和不超过 `10^5`、`M` 之和不超过 `2·10^5`。相邻测试用例之间用一个空行隔开。

**测试点性质**：

- 15% 的数据：`N ≤ 5`；
- 10% 的数据：`M = N`；
- 20% 的数据：若并非对所有 `b` 都有 `f_G(x, b) = f_G(y, b)`，则存在 `b` 使 `f_G(x, b)` 为真且 `f_G(y, b)` 为假（任意两点的需求集合可比较）；
- 30% 的数据：`N ≤ 100`；
- 25% 的数据：无额外限制。

### 题解

**第一步：刻画 `f_G(a, b)`**。设

- `D0(a)` = 从 1 到 `a` 的**偶数长度**最短路径长度；
- `D1(a)` = 从 1 到 `a` 的**奇数长度**最短路径长度（不存在则为 ∞）。

由于可以在同一条边上来回走使任意路径 `+2`，所以

> `f_G(a, b)` 为真 ⟺ `b ≥ D_{b mod 2}(a)`。

（更短的同奇偶路径不存在，否则与最短路矛盾。）因此 **G' 合法 ⟺ 每个点 `a` 的两个阈值 `(D0(a), D1(a))` 都被原样保留**。

**求法**：二分图翻倍——建立 `2N` 个结点 `(v, 0/1)`，原图的每条边 `(x, y)`（含自环）变成 `((x,p), (y,p⊕1))` 两条有向弧，从 `(1, 0)` BFS，得到的 `dis[v]`、`dis[v+N]` 即 `D0(v)`、`D1(v)`。

**第二步：分类讨论**。

- **G 是二分图**（⟺ 1 没有奇数长度回路 ⟺ `D1(1) = ∞`）：奇偶两层完全分离，`f(a, b)` 只在 `b ≡ D0(a) (mod 2)` 时可能为真。取一棵以 1 为根的 BFS 树即可保留所有 `D0`，答案 **N − 1**。
- **G 非二分**：每个点的两维都有限。对每个点令 `(x, y)` 为 `{D0, D1}` 排序后的结果（`x < y` 恒成立）。在翻倍图里，点 `v` 的两个复制 `(v,0)`、`(v,1)` 各自需要一条"父边"：连到距离恰好 `-1` 的复制，即
  - `(v,0)` 需要一个邻居 `u` 使 `D1(u) = D0(v) − 1`；
  - `(v,1)` 需要一个邻居 `u` 使 `D0(u) = D1(v) − 1`。

  考察 `u` 的二元组：
  - 若 `{D0(u), D1(u)} = {x−1, y−1}`（即 `u` 属于 `(x−1, y−1)` 组）：一条边 `v–u` 同时充当两个父边（无论奇偶如何对应都成立），**1 条边解决**；
  - 否则需要 **2 条边**：分别连向 `(x−1, y+1)` 组与 `(x+1, y−1)` 组，各覆盖一维。

  按 `(x+y, x)` 排序后，所有组恰好落在若干条**链** `(x, y) → (x+1, y−1) → (x+2, y−2) → …` 上（链上 `x+y` 不变）。对链上相邻两组（大小 `m0, m1`）：一条跨组边可以同时充当左组的"右上需求"和右组的"左上需求"，所以两组之间需要 `max` 两侧未满足需求 条边；有双亲组 `(x−1, y−1)` 存在时，本组节点改用双亲边、不再占用下一组配额。链尾还剩 `t` 个未满足的"右上需求"：`y = x+1` 时可在组内两两配对（一条边同时满足两个点，需 `⌈t/2⌉` 条），否则各需一条（`t` 条）。第一个处理的组必为 1 号点所在组 `(0, L)`（`x+y` 最小且 `x` 最小），它不需要父边，实现上用"第一组不加"扣除。

  每组处理 O(log N)，总复杂度 **O((N + M) log N)**。

**部分分做法**：

- **15%（N ≤ 5）**：枚举所有 `2^{N(N+1)/2}` 个含自环的简单图 `G'`，逐一做翻倍 BFS 比对阈值，取最小边数。
- **30%（N ≤ 100）**：按上面的完整算法写即可通过（瓶颈在排序与 set，绰绰有余）；或者写一个 O(N²) 的朴素构造。
- **10%（M = N）**：图是一棵树加一条边（恰一个环）。若环是偶环则仍是二分图（N−1）；奇环时只有环上点的两维都有限，环外点挂在环上，可单独讨论，是完整算法的特例。
- **20%（需求集合可比较）**：任意两点的 `(x, y)` 互不"交叉"，每组至多一个点，组内配对问题消失，计数大幅简化（按秩顺次连边即可）。

### 参考实现

见同目录 `connected.cpp`（满分做法，已与"枚举所有 G'"的暴力对拍 340 组随机数据，含 N = 5）。

## T4 crystal（水晶序列）

### 题面

给定一个由 `n` 个水晶组成的序列，从左到右排列。每个水晶属于 `k` 种类型之一，用前 `k` 个英文字母表示。

游戏的一步中，可以从序列中移除一个水晶。玩家的目标是通过允许的删除方式，得到**字典序最小**的字符串。允许的删除方式由 `k × k` 的表 `A` 定义（元素只含 0/1）：若 `A_{i,j} = 1`，表示**当前紧邻它前面的水晶是类型 `i` 时**，允许删除类型 `j` 的水晶。这些操作可以按任意顺序执行。

字典序定义：存在位置 `m` 使得两串在 `m` 之前相同且 `x` 的第 `m` 个字符小于 `y` 的第 `m` 个字符，或 `x` 是 `y` 的严格前缀。

**输入格式**：第一行两个整数 `k, n`（`1 ≤ k ≤ 26`，`1 ≤ n ≤ 5·10^5`）。接下来 `k` 行给出表 `A`，第 `i` 行 `k` 个字符（0 或 1）。最后一行是由 `n` 个小写字母组成的初始序列，只含前 `k` 个字母。

**输出格式**：输出可以得到的字典序最小的字符串。

**子任务**：

| 子任务 | 分值 | n ≤ | k ≤ |
|---|---|---|---|
| 1 | 10 | 20 | 26 |
| 2 | 12 | 50 | 5 |
| 3 | 16 | 300 | 5 |
| 4 | 17 | 500 | 26 |
| 5 | 10 | 2000 | 26 |
| 6 | 9 | 10000 | 26 |
| 7 | 8 | 100000 | 26 |
| 8 | 11 | 500000 | 2 |
| 9 | 7 | 500000 | 26 |

### 题解

**第一步：删除结构的刻画**。把一次删除看成"左边的字符吞掉紧邻的右边字符"。**从右往左**用栈扫描序列：处理到位置 `i` 时，不断弹出栈顶 `j`（满足 `A_{s_i, s_j} = 1`），令 `fa[j] = i`（`j` 被 `i` 删除），直到栈顶不可删；此时栈顶即为 **`nx[i]`**：`i` 删完它能删的一段后，右侧第一个幸存的字符位置。这样得到一片**删除森林**（`fa`/`G[i]` = 被 `i` 直接删除的位置集合，它们在原序列中构成紧邻的一段）。

有一个关键性质（官方题解的"后缀一致"论证）：若取栈的一个后缀进行操作，这些元素的压栈、弹栈行为与完整扫描时完全一致；因此**从 `i` 出发能转移到的"下一个保留位置"，恰好是 `S_i`（被 i 删除的位置集合）中各点 `v` 的最优后继 `f[v]`**，不会有遗漏或多余。

**第二步：DP 求最优串**。设 `f[i]` = 以 `i` 作为首个保留位置时，最优解中 `i` 之后下一个保留的位置；`g[i]` = 从 `i` 开始能得到的最优字符串。则

- 保留方案必然保留 1 号位置（它左边没有字符，永远删不掉）；
- `f[i]` = 在候选 `{ i+1 } ∪ { f[v] : v ∈ G[i] }` 中，选**从该位置开始的最优串**字典序最小者（选 `i+1` 表示不删任何字符；选 `f[v]` 表示删除 `i` 与 `v` 之间的整段）；
- 答案即沿 `1 → f[1] → f[f[1]] → …` 输出的字符序列。

**第三步：快速比较两条链**。`g[i]` 是链 `i, f[i], f[f[i]], …` 上的字符序列。比较两个候选串 = 比较两条 `f` 链的字典序：用**二进制提升 + 字符串哈希**——`f[i][j]` 表示沿链走 `2^j` 步的位置，`h[i][j]` 表示这段 `2^j` 个字符的哈希值；从高位到低位同时跳两条链，哈希相等就跳过，第一个哈希不同的字符决定大小。单次比较 O(log n)。总复杂度 **O(n log n + n log² n)**（瓶颈在候选比较），std 使用双哈希防碰撞。

**实现要点**：

- 建森林时栈底先放一个哨兵 `n+1`（`nx` 的终点），注意 `f[n+1] = 0` 的边界；
- 倒序处理保证计算 `f[i]` 时所有 `f[v]`（`v > i`）已就绪；
- 输出沿 `f[1][0]` 链走即可。

**部分分做法**：

- **10 分（n ≤ 20）**：直接 BFS/DFS 搜索所有可达字符串（每次枚举删哪个字符），取最小串。
- **12 + 16 + 17 + 10 分（n ≤ 50/300/500/2000）**：栈 O(n) 建出 `nx`/删除森林，`f[i]` 的候选直接**朴素比较字符串**（逐字符 + 及时退出）。候选总数 O(n)，每次比较均摊 O(n)，n ≤ 2000 绰绰有余，共约 65 分。
- **11 分（k = 2，n ≤ 5·10^5）**：字符只有两种，比较可以特判得更快（或用位运算维护）；也可以用单哈希 + 倍增的完整做法顺手通过。
- **25 分（n ≤ 10^4 / 10^5 / 5·10^5）**：需要完整做法。进一步优化：把哈希比较换成后缀数组/后缀自动机可做到 O(n log n)；std 的双哈希实现已足够（`O(n log n)` 预处理 + 每个候选 `O(log n)` 比较，总 `O(n log n · 出度)`，利用"候选总数 O(n)"即 `O(n log n)`～`O(n log² n)`）。
